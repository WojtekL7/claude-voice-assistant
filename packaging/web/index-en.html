Claude Voice Assistant

Talk to Claude Code with your voice — dictate commands and listen to the answers. Download it, install it like any other app, and go. No fuss.

Your system
🍎
macOS
Apple Silicon (M1–M4)
⬇ Download for Mac 📖 Step-by-step guide (for everyone)
How to install: open the downloaded .dmg file and drag the icon into the Applications folder. On first launch: System Settings → Privacy & Security → “Open Anyway”.
Your system
🐧
Linux
AppImage (64-bit) — no installation
⬇ Download for Linux 📖 Step-by-step guide (for everyone)
How to run it: after downloading, right-click the file → Properties → Permissions and tick “Allow executing as program”, then open it with a double-click. The app then updates itself.
Your system
🪟
Windows
Windows 10/11 (64-bit) — installer
⬇ Download for Windows 📖 Step-by-step guide (for everyone)
How to install: open the downloaded .exe file and click through the installer (a few “Next” clicks). If a “Windows protected your PC” screen appears, click More info → Run anyway. The app updates itself from then on.

How it works — in three steps

1

Download

Click the button for your system above. The file saves to your “Downloads”.

2

Install

Open the downloaded file and follow the short hint under the button.

3

Speak and listen

Launch the app, allow microphone access, and talk to Claude Code with your voice.
