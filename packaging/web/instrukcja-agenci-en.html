Manage agents — step by step

How to add a new agent and what every option in this window means — explained so anyone can understand it, with no technical knowledge at all.

← Back to the download page

What even is an “agent”?

Picture an agent as a separate employee you hire for one project. Each agent has its own tab in the app (like tabs in a browser), and inside it:

  • its own terminal — the “desk” it works at,
  • its own project folder (working directory) — the folder on disk where it operates,
  • its own “brain” (a Claude model) — faster and cheaper, or more powerful,
  • its own notes (memory files) — which it gets to read at the start.
Why have several agents? For example: one handles an online store, another the company website — each in its own folder, nothing gets mixed up. Or: one with a fast, cheap brain for small stuff, and another with the most powerful one for the hardest tasks. You switch between them by clicking the tabs at the top of the window.

1 How to open “Manage agents”

There are two ways — both lead to the same window:

  • the Tabs → Manage agents… menu (top menu bar), or
  • click “+” on the tab bar and choose Manage agents…

2 The “Manage agents” window — what you see here

On the left is a list of all agents. Each row shows:

  • the agent's name (in a larger font),
  • below it in fine print: 📁 how many memory files it has (hover to see which ones), 🤖 which model (brain) it has, 🧩 how many skills and 🔌 how many MCP plugins (they take a moment to load — that's normal).
The row's background color means something:
 green background = the agent starts on its own every time the app launches,
 gray background = the agent is saved but waiting — you'll start it manually when you need it.

The buttons to the right of the list

▲ Up / ▼ Down Changes the order of agents in the list — the tabs at the top of the window will be arranged in the same order. Select an agent and click the arrows.
▶️ Run Opens the selected agent's tab right away (the window closes, and your changes are saved). The fastest way to wake up an agent with a gray background.
➕ Add Creates a new agent — opens the configuration window described in point 3 below.
✏️ Edit Opens the same configuration window, but with the selected agent's settings — you can change its name, folder, model, and so on.
📋 Duplicate Creates a copy of the selected agent (with “(copy)” added to the name). Handy when you want a second, nearly identical one — e.g. the same project but with a different brain.
🗑️ Delete Deletes the selected agent (the app will ask if you're sure). At least one agent must remain — you can't delete the last one.
Cancel / Save (at the bottom) Save confirms all changes. If you didn't use “Run” or “Save and run,” the new tabs will appear after you restart the app (the app will remind you). Cancel discards changes.

3 Adding a new agent — the configuration window

After you click ➕ Add (or ✏️ Edit), a window opens with four tabs at the top: 📝 Basics, 💾 Memory, 🧩 Skills, 🔌 MCP. For ordinary work the first one is enough — the rest are extras for those who want them.

📝 The “Basics” tab — where the most important stuff happens

Agent name Any name that reminds you what this agent does — e.g. “Online store” or “Company website.” It'll appear on the tab.
Working directory The “project folder” — the folder on disk where the agent will work (reading and creating files). Click 📁 next to the field and pick a folder. If you're starting from scratch — first create an empty folder, e.g. Documents\MyProject.
Claude Code model The agent's “brain.” From the list you can pick:
  • Default — Opus 4.8 — good for everything, start with this;
  • Fable 5 — the most powerful, for the hardest tasks (uses up your account's limit about 2× faster — use it consciously);
  • Opus 4.8 — same as the default, locked in explicitly;
  • Sonnet 4.6 — fast and balanced, for lighter work;
  • Haiku 4.5 — the fastest and most economical, for simple questions.
Below the list there's a hint: changing the model of a running agent requires restarting it (the Stop button, then Run in the tab).
☑ Start automatically when the app launches Checked = the agent wakes up on its own together with the app (green background in the list). Unchecked = it waits until you start it by hand. If you have many agents, leave this checked only for the ones you use every day — the app will start faster.
☑ Load memory files after Claude Code starts Checked = right after starting, the agent immediately “reads” the notes from the 💾 Memory tab. Uncheck only if you want to exceptionally start without them.

💾 The “Memory” tab — notes for the start

Here you add files the agent gets to read at the beginning of its work — like a folder of notes for a new employee: what this project is, what the rules are, what's already been decided. This way you don't have to explain everything from scratch in every conversation.

  • Click + Add file and pick a file from disk — these can be .md files (formatted text), .txt (plain text) or .json.
  • Each added file appears as a bar with its name; the ✕ on the right removes it (from the agent's list — the file on disk stays untouched).
  • Hover over the name to see the file's full path.
No notes at all? No problem — leave it empty. The agent works without this too; memory is a convenience, not a requirement.

🧩 The “Skills” tab — extra abilities (for those who want them)

A skill is a ready-made “recipe” that teaches the agent a specific ability — e.g. creating Word documents, presentations, or searching the internet according to certain rules.

  • Every agent automatically inherits the global skills (the ones from the Extensions menu — shared across all agents).
  • The “Manage local skills” button lets you add skills for this one agent only.
  • The list at the bottom (“🚫 Disable global skills…”) lets you uncheck those shared skills that this particular agent should not use. Changes are saved right away.

🔌 The “MCP” tab — plugins for tools (for those who want them)

MCP plugins give the agent access to external tools — e.g. a database, a web browser, or a calendar. It works exactly like skills:

  • the agent inherits the global MCP servers from the Extensions menu,
  • “Manage local MCP” adds plugins for this agent only (they run in its working directory),
  • the “🚫 Disable global MCP…” list detaches selected shared plugins from this agent (saved instantly).
If you don't know what skills and MCP are — just skip these two tabs. The agent will work great without them.

The buttons at the bottom of the configuration window

CancelCloses the window without saving.
Save Adds the agent to the list (returns to the “Manage agents” window). Its tab will open after you restart the app — or select it and click ▶️ Run.
Save and run Saves and immediately opens the tab of the new agent. The most convenient option when you want to start working right away.

4 Quick recipe: your first own agent in 6 steps

  1. Create an empty folder on disk for the project, e.g. Documents\MySite.
  2. In the app: the Tabs → Manage agents… menu.
  3. Click ➕ Add.
  4. Type a name (e.g. “My site”), click 📁 and point to the folder you created. Leave the model on Default.
  5. Click Save and run.
  6. Done — you have a new tab. Write what you want to do in it and press Enter.
✅ An everyday tip: a handy setup is two agents — one with the Opus model (the default) for day-to-day work and another with Fable 5 for the hardest tasks. Make a copy with the 📋 Duplicate button and change only the model on the copy.

Frequently asked questions

I added an agent but I don't see its tab You clicked “Save” without running it — the tab will appear after you restart the app. Or go back to “Manage agents,” select it and click ▶️ Run.
I changed the model but the agent still answers the old way A running agent needs to be restarted: in its tab click Stop, then Run.
I can't delete an agent You can't delete the last agent — at least one must remain.
“⏳ loading…” hangs for a long time next to 🧩 and 🔌 That's normal — the app is asking Claude Code for the list of skills and plugins of each agent. After a few seconds the numbers will appear.
What does a green and a gray background in the list mean? Green = the agent starts on its own when the app launches. Gray = it's waiting for a manual start. You change this in ✏️ Edit → “Start automatically…”.
Do agents see each other's conversations? No — each one works separately, in its own terminal and its own folder.
