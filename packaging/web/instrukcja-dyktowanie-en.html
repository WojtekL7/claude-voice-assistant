Voice dictation — step by step

How to talk to the program instead of typing. You need one free key — we'll show you how to get it in a few minutes, with no technical knowledge at all.

← Back to the download page

Why do I need this key?

Dictation turns your voice into text — you speak, and the words type themselves into the terminal. The voice-to-text work is done by a free online service called Groq (think of it as a fast, free "transcription machine").

So the program can use it on your behalf, it needs an API key — a kind of personal passcode, like your own remote for a gate. You set it up once, paste it into the program, and you're done.

Does it cost anything? No. The Groq account and the key are free, and the free allowance is more than enough for dictation. No payment card is required.
⚠️ Dictation is optional. The program works great without it — reading answers aloud (TTS) and everything else need no key at all. The Groq key is only needed if you want to talk to the program.

1 Create a free Groq account

Open the Groq sign-in page in your browser:

🌐 Open console.groq.com/login

Sign in the easiest way — with a Google account, GitHub, or a plain email. If it's your first time, the account is created automatically on your first sign-in.

It's an ordinary sign-in, like any other website. You don't enter a card number or any payment details.

2 Create an API key

Once signed in, go to the keys section:

🔑 Open console.groq.com/keys
  1. Click the "Create API Key" button.
  2. Type any name so you'll remember what it's for — e.g. Claude Voice Assistant — and confirm.
  3. A long string of characters starting with gsk_… will appear. That's your key.
  4. Click "Copy" — or select it all and copy (Ctrl+C, on Mac ⌘+C).
⚠️ Important: this key is shown only once, right after you create it. Copy it straight away. If you lose it — no problem, just create a new one in the same place and delete the old one.
Treat the key like a password. Don't paste it into a chat or email it to anyone. You'll paste it in just one place — the program, in the next step.

3 Paste the key into the program

Go back to Claude Voice Assistant and open the key settings window:

  • menu Settings → API key (dictation)…, or
  • click the 🎙️ Dictate icon in a tab — if there's no key yet, the program will offer to enter it.
  1. Paste the copied key into the field (Ctrl+V, on Mac ⌘+V).
  2. Click Save.
✅ Done! The key is saved on your computer and the program remembers it for good — you enter it only once.

4 Test dictation

  1. Open an agent tab and click 🎙️ Dictate (or use the keyboard shortcut).
  2. Say a short sentence, e.g. "show me the list of files in this folder".
  3. After a moment your words appear as text in the field. Click 🎙️ again to stop recording.
The first voice-to-text may take a moment — that's normal. Speak clearly, with little background noise. English and Polish are detected automatically.

5 How to start dictation in the program

Once the key is pasted, you turn dictation on in any agent tab — no restart needed:

  1. Open an agent tab. In the bottom button bar (under the terminal, next to the field where you type commands) find the round 🎙️ microphone icon (hovering shows the tooltip "Dictate").
  2. Click the microphone once to start — the button stays highlighted, meaning the program is listening.
  3. Say what you want to pass on. Speak clearly, with little background noise; English and Polish are detected automatically.
  4. Click the microphone again to finish. After a moment your words appear as text in the input field — you can edit them and send with Enter.
No key yet? If you click the microphone and the Groq key isn't entered, the program will first ask you to add it (see steps 1–3 above).
⚠️ Dictation starts only via the microphone button — there is no keyboard shortcut. The first voice-to-text may take a moment; the next ones are faster.

Frequently asked questions

Do I have to enter a payment card? No. The Groq account and key are free, and the free allowance is plenty for dictation.
I lost the key / didn't copy it Nothing lost. Go back to console.groq.com/keys, delete the old key (trash icon) and click Create API Key to make a new one.
Dictation doesn't work even though I pasted the key Check that the key starts with gsk_ and was pasted in full (no trailing space). Also make sure a microphone is connected and the program is allowed to use it in your system settings.
Is my voice stored anywhere? The recording is sent to Groq only to turn it into text, and is not kept by the program. The key stays only on your computer.
Can I use the same key on several computers? Yes — you can paste the same key on each of your devices. You can also create a separate key per computer if you prefer.
I don't want to dictate — do I have to set this up? No. Skip this guide — the program works fully without the key. In the settings window you can tick "don't remind me about dictation" so the program stops asking.
