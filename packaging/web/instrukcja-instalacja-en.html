🧭 Before we start — two paths

This app (Vibe Coding Assistant) is a remote control: it gives you voice, tabs and a comfortable window. The thinking is done by Claude Code, and for it to work it needs your Claude account.

On a Mac the app installs entirely by clicking (you drag the icon to Applications). The choice of path applies to just one moment — adding the “brain” in part 2:

A With a terminal — you paste a ready command. Reliable, always works.
B Without a terminal — a wizard in the app guides you. For non-technical users.
⚠️ A bit of honesty: installing Claude Code has no click-through installer — you run it once in the Terminal app. On path B the app gives you a ready command with a Copy button, so you just paste and Enter.
💜 You never retype anything by hand — every command has a Copy button.

1 Download and install the app

  1. On the download page click “⬇ Download for Mac”.
  2. It downloads VibeCodingAssistant-macos.dmg. Double-click it — a small window opens.
  3. Drag the app icon onto the “Applications” shortcut in that window.
  4. Open Launchpad or the Applications folder and launch Vibe Coding Assistant.
⚠️ On first launch macOS may say the app is from an “unidentified developer”. Go to System Settings → Privacy & Security, find the message about the app and click “Open Anyway”. (Or: right-click the app icon → Open.)
✅ The app opened — great, you'll need it in part 2.

2 Add the “brain” — Claude Code

The app doesn't think on its own — it needs Claude Code (a free add-on, installed once, together with the helper Node.js).

B Without a terminal — let the app guide you (recommended)
  1. In the running app, if it can't find Claude Code, a “Finish setup” window appears.
  2. Click “Get Node.js” — it opens nodejs.org. Download the LTS version and install it (click “Continue”). After installing Node, restart the app so it notices it.
  3. The “Finish setup” window has a ready command and a Copy button. This is the one moment with a terminal: open the Terminal app (see below), paste the command (⌘+V) and press Enter.
  4. Go back to the app window and click “Check again”. The app finds the brain and moves on.
💡 How to open Terminal: press ⌘+Space, type Terminal and press Enter. A window opens — that's our “terminal”.
💡 You can open the “Finish setup” window yourself: menu Help → Claude Code setup.
A With a terminal — by yourself
  1. Install Node.js (LTS) from nodejs.org (a normal installer, click “Continue”).
  2. Open the Terminal app (⌘+Space → “Terminal” → Enter) and paste:
npm install -g @anthropic-ai/claude-code
⚠️ Got a permission error (EACCES)? Paste the same command with sudo in front and enter your Mac password (no characters show while typing — that's normal):
sudo npm install -g @anthropic-ai/claude-code
✅ Check: type claude --version and Enter. See a number? The brain is in place.

3 Create a Claude account and pick a plan

For Claude Code to work you need a Claude account with paid access. You can do this earlier too — what matters is that it's ready before the login in part 4.

3.1 Create the account

  1. Go to claude.ai (button below) and click “Sign up”.
  2. Choose to sign up with an email or a Google account.
  3. With email — confirm using the code/link from your inbox (check Spam too).
🔗 Open claude.ai and sign up

3.2 Pick a plan

A free account is enough for chatting on the website, but Claude Code needs paid access. Two routes:

💜 Pro / Max plan — recommended

A fixed monthly fee on your claude.ai account. Simplest: pay once a month and log in with that account. Pro is enough to start, Max gives you more for heavy use.

🔧 Pay via the API (advanced)

“Pay as you go” billing in the console.anthropic.com dashboard. More fiddly — skip it unless you know you need it.

🔗 Choose a plan on claude.ai
💡 Not sure? Start with Claude Pro — you can change or cancel any time.

4 Connect the account to the app (login)

Now we connect the account to the app — done inside the app, once.

  1. A terminal (a dark panel) appears in the app. The first time you start an agent, Claude Code asks you to log in.
  2. A browser should open — sign in to your Claude account (from part 3) and click “Authorize”.
  3. The browser shows a code. Copy it and paste it into the app where it says “Paste code here”, then Enter.
⚠️ Browser didn't open by itself? Claude Code shows a long link and a hint “press c to copy”. Press c (the link goes to the clipboard), paste it in your browser. Don't retype the link by hand.

5 Check it works — and what to do if it doesn't

✅ Quick test

  • An agent tab with a working terminal has appeared.
  • Type or say: “Hi, are you working?” — Claude replies, and the app reads the answer out loud.
  • From now on you launch the app from Launchpad or the Applications folder — and it updates itself.
🎉 Claude replies? You're all set. Enjoy!

🛟 Something not working? Cheat sheet

  • “command not found: claude”. The brain is installed but the app doesn't see it yet — close and reopen the app. Still nothing? Go back to part 2.
  • macOS won't open the app (“unidentified developer”). System Settings → Privacy & Security → Open Anyway (part 1).
  • The app keeps asking you to log in. Sign in with the account that has a paid plan (part 3) — a free one isn't enough.
  • The browser won't open during login. Use the c method (part 4).
  • Still stuck? Email us: kontakt@fulfillment-polska.pl.

🧰 What a “terminal” is (only needed for path A and one command)

A terminal is a small window where, instead of clicking, you type commands as text. It looks scary, but you'll only be pasting ready-made commands from this page.

  • Open a terminal: press Ctrl + Alt + T together.
  • Paste into the terminal: Ctrl + Shift + V (or right-click → “Paste”).
  • Confirm: Enter.
⚠️ When a command starts with sudo, the terminal asks for your password (the one you log into the computer with). While typing it no dots or stars appear — that's normal. Type it “blind” and press Enter.

1 Download and run the app

On Linux the app is a single file of the AppImage type — no installer. You download it and run it with a double-click, like a game icon.

1.1 Download the file

  1. On the download page click “⬇ Download for Linux”.
  2. It downloads VibeCodingAssistant-linux.AppImage (about 190 MB) into your Downloads folder.
✅ You have a file in Downloads with a purple icon (a white “›” arrow with sound-wave bars) ending in .AppImage.

1.2 Allow the file to run

Out of caution, Linux won't run a freshly downloaded file until you confirm it's a program. You do this once.

A Via the terminal (reliable)
  1. Open a terminal (Ctrl+Alt+T).
  2. Copy the line below (there's a space at the end) — don't press Enter yet:
chmod +x
  1. Paste it into the terminal, then drag the downloaded .AppImage file into the terminal window and drop it — the path is added by itself.
  2. Press Enter. No message = success (silence is good news).
B Via the file manager (with the mouse)
  1. Open the Downloads folder, right-click the file → Properties.
  2. Permissions tab → tick “Allow executing file as program”.
⚠️ Newer Ubuntu sometimes hides this option. Don't see it? Use path A.

1.3 Run it

Go back to Downloads and double-click the .AppImage file. The app window opens after a moment.

⚠️ Double-click does nothing, or an error about “libfuse.so.2”? A small library is missing — paste this in a terminal and press Enter:
sudo apt update && sudo apt install -y libfuse2
