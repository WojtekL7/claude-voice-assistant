Pełna instrukcja instalacji

Wybierz swój system w górnym menu. Wszystko krok po kroku, tak żeby zrozumiał każdy — bez wiedzy technicznej.

← Wróć do strony pobierania

📍 Co zrobimy — po kolei

  1. Pobierz i zainstaluj program
  2. Dodaj „mózg” — Claude Code
  3. Załóż konto Claude i wybierz plan
  4. Połącz konto z programem (logowanie)
  5. Sprawdź, czy działa — i co, gdy nie

🧭 Zanim zaczniemy — dwie drogi

Ten program (Vibe Coding Assistant) to pilot: daje głos, zakładki i wygodne okno. „Myśli” za niego Claude Code, a żeby działał, potrzebuje Twojego konta Claude.

Na Macu instalacja programu jest w całości klikana (przeciągasz ikonę do Programów). Wybór drogi dotyczy tylko jednego momentu — dodania „mózgu” w części 2:

A Z terminalem — sam wklejasz gotową komendę. Pewne, działa zawsze.
B Bez terminala — prowadzi Cię kreator w programie. Dla osoby nietechnicznej.
⚠️ Mała szczerość: instalacja Claude Code nie ma czysto-klikanego instalatora — trzeba ją odpalić raz w aplikacji Terminal. W drodze B program poda Ci gotową komendę z przyciskiem Kopiuj, więc tylko wklejasz i Enter.
💜 Nigdzie nic nie przepisujesz ręcznie — przy każdej komendzie jest przycisk Kopiuj.

1 Pobierz i zainstaluj program

  1. Na stronie pobierania kliknij „⬇ Pobierz na Maca”.
  2. Pobierze się plik VibeCodingAssistant-macos.dmg. Kliknij go dwa razy — otworzy się okienko.
  3. Przeciągnij ikonę programu na skrót „Programy” (Applications) w tym okienku.
  4. Otwórz Launchpad lub folder Programy i uruchom Vibe Coding Assistant.
⚠️ Przy pierwszym uruchomieniu macOS może powiedzieć, że program jest „z nieznanego źródła”. Wejdź w Ustawienia systemowe → Prywatność i bezpieczeństwo, znajdź komunikat o programie i kliknij „Otwórz mimo to”. (Albo: kliknij ikonę programu prawym przyciskiem → Otwórz.)
✅ Program się otworzył — świetnie, przyda się w części 2.

2 Dodaj „mózg” — Claude Code

Program sam nie myśli — potrzebuje Claude Code (darmowy dodatek, instaluje się raz, razem z pomocniczym Node.js).

B Bez terminala — niech poprowadzi program (polecane)
  1. W uruchomionym programie, jeśli nie znajdzie Claude Code, pokaże się okno „Dokończ instalację”.
  2. Kliknij „Pobierz Node.js” — otworzy stronę nodejs.org. Pobierz wersję LTS i zainstaluj (klikasz „Dalej / Continue”). Po instalacji Node uruchom program ponownie, żeby go zauważył.
  3. W oknie „Dokończ instalację” jest gotowa komenda i przycisk Kopiuj. To ta jedna chwila z terminalem: otwórz aplikację Terminal (patrz niżej), wklej komendę (⌘+V) i naciśnij Enter.
  4. Wróć do okna programu i kliknij „Sprawdź ponownie”. Program znajdzie mózg i ruszy dalej.
💡 Jak otworzyć Terminal: naciśnij ⌘+spacja, wpisz Terminal i naciśnij Enter. Otworzy się okienko — to nasz „terminal”.
💡 Okno „Dokończ instalację” wywołasz też sam: menu Pomoc → Konfiguracja Claude Code.
A Z terminalem — samodzielnie
  1. Zainstaluj Node.js (LTS) ze strony nodejs.org (zwykły instalator, klikasz „Continue”).
  2. Otwórz aplikację Terminal (⌘+spacja → „Terminal” → Enter) i wklej:
npm install -g @anthropic-ai/claude-code
⚠️ Pojawił się błąd o braku uprawnień (permission / EACCES)? Wklej tę samą komendę z dopiskiem sudo na początku i podaj hasło do Maca (podczas wpisywania nie widać znaków — to normalne):
sudo npm install -g @anthropic-ai/claude-code
✅ Sprawdzenie: wpisz claude --version i Enter. Pokazał się numer? Mózg na miejscu.

3 Załóż konto Claude i wybierz plan

Żeby Claude Code działał, potrzebujesz konta Claude z płatnym dostępem. Możesz to zrobić też wcześniej — ważne, żeby było gotowe przed logowaniem w części 4.

3.1 Załóż konto

  1. Wejdź na claude.ai (przycisk niżej) i kliknij „Sign up”.
  2. Wybierz rejestrację e-mailem albo kontem Google.
  3. Przy e-mailu — potwierdź kodem/linkiem z poczty (sprawdź też folder Spam).
🔗 Otwórz claude.ai i załóż konto

3.2 Wybierz plan

Darmowe konto wystarcza do rozmów na stronie, ale Claude Code wymaga płatnego dostępu. Dwie drogi:

💜 Plan Pro / Max — polecane

Stała opłata miesięczna na koncie claude.ai. Najprościej: płacisz raz w miesiącu i logujesz się tym kontem. Pro wystarcza na start, Max daje więcej do intensywnej pracy.

🔧 Rozliczenie przez API (zaawansowane)

Płatność „za zużycie” w panelu console.anthropic.com. Bardziej kłopotliwe — zostaw, jeśli nie wiesz, czy go potrzebujesz.

🔗 Wybierz plan na claude.ai
💡 Niepewny? Zacznij od Claude Pro — plan zmienisz lub anulujesz w każdej chwili.

4 Połącz konto z programem (logowanie)

Teraz łączymy konto z programem — robi się to w samym programie, raz.

  1. W programie powstaje terminal (ciemne pole). Przy pierwszym uruchomieniu agenta Claude Code poprosi o zalogowanie.
  2. Powinna otworzyć się przeglądarka — zaloguj się na konto Claude (to z części 3) i kliknij „Autoryzuj”.
  3. Przeglądarka pokaże kod. Skopiuj go i wklej w programie w miejscu „Paste code here”, potem Enter.
⚠️ Przeglądarka nie otworzyła się sama? Claude Code pokaże długi link i podpowiedź „press c to copy”. Naciśnij c (link trafi do schowka), wklej go w przeglądarce. Nie przepisuj linku ręcznie.

5 Sprawdź, czy działa — i co, gdy nie

✅ Szybki test

  • Powstała zakładka agenta z działającym terminalem.
  • Napisz lub powiedz: „Cześć, działasz?” — Claude odpowie, a program przeczyta odpowiedź głosem.
  • Od teraz uruchamiasz program z Launchpada lub folderu Programy — i sam się aktualizuje.
🎉 Claude odpowiada? Wszystko gotowe. Miłej rozmowy!

🛟 Coś nie działa? Ściąga

  • „command not found: claude”. Mózg jest, ale program go nie widzi — zamknij i otwórz program ponownie. Jeśli dalej nic — wróć do części 2.
  • macOS nie chce otworzyć programu („z nieznanego źródła”). Ustawienia systemowe → Prywatność i bezpieczeństwo → Otwórz mimo to (część 1).
  • Program prosi o logowanie w kółko. Loguj się na konto z opłaconym planem (część 3) — darmowe nie wystarcza.
  • Przeglądarka nie otwiera się przy logowaniu. Użyj sposobu z klawiszem c (część 4).
  • Dalej nie działa? Napisz: kontakt@fulfillment-polska.pl.
Masz też Linuksa lub Windowsa? Zobacz: Pełna instrukcja Linux • Pełna instrukcja Windows

🧰 Co to „terminal” (potrzebne tylko w drodze A i przy jednej komendzie)

Terminal to małe okienko, w którym zamiast klikać — wkleja się polecenia tekstem. Wygląda groźnie, ale Ty będziesz tylko wklejać gotowce z tej strony.

  • Otworzyć terminal: naciśnij naraz Ctrl + Alt + T.
  • Wkleić do terminala: Ctrl + Shift + V (albo prawy przycisk → „Wklej”).
  • Zatwierdzić: Enter.
⚠️ Gdy komenda zaczyna się od sudo, terminal poprosi o hasło (to do logowania w komputerze). Podczas wpisywania nie widać kropek ani gwiazdek — to normalne. Wpisz „w ciemno” i Enter.

1 Pobierz i uruchom program

Na Linuksie program to jeden plik typu AppImage — bez instalatora. Pobierasz go i uruchamiasz dwuklikiem, jak ikonę gry.

1.1 Pobierz plik

  1. Na stronie pobierania kliknij „⬇ Pobierz na Linux”.
  2. Pobierze się plik VibeCodingAssistant-linux.AppImage (ok. 190 MB) do folderu Pobrane.
✅ W folderze Pobrane masz plik z fioletową ikoną mikrofonu kończący się na .AppImage.

1.2 Pozwól plikowi się uruchamiać

Linux z ostrożności nie pozwoli uruchomić świeżo pobranego pliku, dopóki nie potwierdzisz, że to program. Robi się to raz.

A Przez terminal (pewne)
  1. Otwórz terminal (Ctrl+Alt+T).
  2. Skopiuj poniższe (jest tu spacja na końcu) — jeszcze nie naciskaj Enter:
chmod +x
  1. Wklej do terminala, potem przeciągnij myszką pobrany plik .AppImage do okna terminala i upuść — ścieżka dopisze się sama.
  2. Naciśnij Enter. Brak komunikatu = sukces (cisza to dobra wiadomość).
B Przez menedżer plików (myszką)
  1. Otwórz folder Pobrane, kliknij plik prawym przyciskiem → Właściwości.
  2. Zakładka Uprawnienia → zaznacz „Zezwól na wykonywanie pliku jako programu”.
⚠️ Nowsze Ubuntu czasem ukrywa tę opcję. Nie widzisz jej? Użyj drogi A.

1.3 Uruchom

Wróć do folderu Pobrane i kliknij dwa razy plik .AppImage. Po chwili otworzy się okno programu.

⚠️ Dwuklik nic nie robi lub błąd o „libfuse.so.2”? Brakuje małej biblioteki — wklej w terminalu i Enter:
sudo apt update && sudo apt install -y libfuse2

B Bez terminala — niech poprowadzi program (polecane)
