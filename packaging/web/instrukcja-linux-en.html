1 What you can set up today — Node.js and Claude Code

The app (just like on every system) needs two free add-ons: Node.js and Claude Code. You can install them today — they'll be ready for the package launch. Open a terminal (Ctrl+Alt+T on Ubuntu) and run these one after another:

Node.js (Ubuntu/Debian):

sudo apt update && sudo apt install -y nodejs npm

Claude Code:

sudo npm install -g @anthropic-ai/claude-code
✅ Check: type claude --version and press Enter — if a version number shows up, you're all set.

2 Signing in to Claude Code

  1. In the terminal, type claude and press Enter.
  2. If you're asked whether you trust the folder — press Enter (yes).
  3. Claude Code will ask you to sign in. A browser should open — sign in to your Claude account (claude.ai, e.g. a Pro plan) and click Authorize.
  4. Copy the code that appears and paste it into the terminal where it says “Paste code here.”
⚠️ If the browser doesn't open on its own — Claude Code will show a long link and a hint that says “c to copy.” Press c (the link copies to your clipboard), then paste it into your browser. Don't retype the link by hand.
