Installing on Linux — step by step

Written for someone who has never installed anything on Linux and doesn't know what a terminal is. Relax — we'll do it together.

← Back to the download page

📦 What you get and what to do

On Linux the program is a single file (an AppImage) — there's no “installer” like on Windows. You keep the file and launch it with a double-click, like a game icon.

To get everything running, we'll do 5 things in order:

  1. Download the program file from the page.
  2. Allow the file to run (Linux won't do this on its own, to be safe).
  3. Launch the program (double-click).
  4. One time only, add the program's “brain” — the free Claude Code.
  5. Log in to your Claude account.
💜 Most important: you never retype anything by hand. Wherever a black box with a command appears, there's a Copy button next to it. Copy, paste, Enter.

🧰 First, relax: what is a “terminal”

A terminal is a small window where, instead of clicking, you type commands as text. It looks scary, but all you'll do is paste ready-made commands from this page. That's it.

  • How to open the terminal: press Ctrl + Alt + T together. A black (or purple) window opens. That's the terminal.
  • How to paste into it: copy the command with the button, go back to the terminal and press Ctrl + Shift + V (or right-click → “Paste”).
  • How to confirm: after pasting, press Enter.
⚠️ If a command starts with sudo, the terminal will ask for your password (the same one you use to log into the computer). While you type it, no dots or stars appear — that's normal. Type it “blind” and press Enter.

1 Download the program

  1. On the download page click the big “⬇ Download for Linux” button.
  2. Your browser downloads a file named ClaudeVoiceAssistant-linux.AppImage (about 190 MB — it may take a moment).
  3. The file lands in your Downloads folder — where all your downloads go.
✅ You now have a file in Downloads with a purple microphone icon and a name ending in .AppImage — great, let's continue.

2 Allow the file to run

To be safe, Linux treats a freshly downloaded file as an “ordinary document” and won't run it until you confirm it's a program. You do this once. Pick one of the two methods — method A always works.

Method A — via the terminal (reliable, recommended)

  1. Open the terminal: Ctrl + Alt + T.
  2. Type chmod +x followed by one space (don't press Enter yet):
chmod +x
  1. Now drag the downloaded .AppImage file straight into the terminal window and drop it. The file's path fills in by itself — no typing needed.
  2. Press Enter. No message = success (that's how the terminal works — silence is good news).
💡 The whole line will look roughly like this: chmod +x /home/yourname/Downloads/ClaudeVoiceAssistant-linux.AppImage

Method B — via the file manager (if yours supports it)

  1. Open the Downloads folder, right-click the file → Properties.
  2. Go to the Permissions tab.
  3. Tick “Allow executing file as program” and close the window.
⚠️ Some newer systems (e.g. the latest Ubuntu) have hidden this option in the file manager. If you don't see such a checkbox — just use Method A (terminal).

3 Launch the program

Go back to the Downloads folder and double-click the .AppImage file. After a moment the program window should open.

⚠️ Double-click does nothing, or you get an error about “libfuse.so.2”? This is very common on newer Ubuntu — one small library is missing. Paste this in the terminal (Ctrl+Alt+T) and press Enter:
sudo apt update && sudo apt install -y libfuse2

Then try double-clicking the file again.

💡 If a dialog asks “Do you want to run…?” — confirm Run.

4 Add the program's “brain” — Claude Code

This program doesn't think on its own — it's a remote control for Claude Code (that's what talks and writes code). Claude Code is free and installs once. If the program shows a setup wizard after launch — just follow its steps. Prefer to do it manually? Open the terminal and paste one after another:

a) Node.js (a free helper program)

sudo apt update && sudo apt install -y nodejs npm

b) Claude Code

sudo npm install -g @anthropic-ai/claude-code
✅ Check: type claude --version and press Enter. A version number showed up? The brain is in place.

5 Log in to Claude

  1. In the terminal type claude and press Enter (or do it in the terminal inside the program).
  2. If asked whether to trust the folder — press Enter (yes).
  3. Claude Code asks you to log in. A browser should open — sign in to your Claude account (claude.ai, e.g. the Pro plan) and click Authorize.
  4. Copy the code shown and paste it in the terminal where it says “Paste code here”.
⚠️ If the browser doesn't open by itself — Claude Code shows a long link and a “c to copy” hint. Press c (the link is copied to the clipboard), then paste it into the browser. Don't retype the link by hand.
🎉 Done! From now on you launch the program with a normal double-click of the .AppImage file. The program updates itself — when a new version appears, it offers it.

🛟 Something's not working? Quick cheat sheet

  • Double-click does nothing. Most likely you skipped step 2 (allow running) or libfuse2 from step 3 is missing. Do both and try again.
  • “command not found: claude”. The brain is missing — go back to step 4.
  • I don't know where the file is. Open “Files” (the file manager) → the Downloads folder.
  • The terminal asks for a password and “nothing types”. That's normal — the password is hidden. Type it blind and press Enter.
  • A different system than Ubuntu (Fedora, Arch…)? The apt commands may differ — write to us and we'll help: kontakt@fulfillment-polska.pl.
