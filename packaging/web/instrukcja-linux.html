Instalacja na Linuksie — krok po kroku

Pisane dla osoby, która nigdy nie instalowała nic na Linuksie i nie wie, co to terminal. Spokojnie — przejdziemy przez to razem.

← Wróć do strony pobierania

📦 Co dostajesz i co trzeba zrobić

Na Linuksie program to jeden plik (typu AppImage) — nie ma „instalatora” jak na Windowsie. Plik nosisz ze sobą i uruchamiasz dwuklikiem, jak ikonę gry.

Żeby wszystko ruszyło, zrobimy po kolei 5 rzeczy:

  1. Pobrać plik programu ze strony.
  2. Pozwolić plikowi się uruchamiać (Linux z ostrożności tego nie robi sam).
  3. Uruchomić program (dwuklik).
  4. Jednorazowo dodać „mózg” programu — darmowe Claude Code.
  5. Zalogować się na swoje konto Claude.
💜 Najważniejsze: nigdzie nic nie przepisujesz ręcznie. Gdzie pojawi się czarna ramka z komendą — masz przy niej przycisk Kopiuj. Kopiujesz, wklejasz, Enter.

🧰 Najpierw spokojnie: co to jest „terminal”

Terminal to małe okienko, w którym zamiast klikać — wpisuje się polecenia tekstem. Wygląda groźnie, ale Ty będziesz tylko wklejać gotowe komendy z tej strony. To wszystko.

  • Jak otworzyć terminal: naciśnij naraz Ctrl + Alt + T. Otworzy się czarne (lub fioletowe) okienko. To jest terminal.
  • Jak wkleić do terminala: skopiuj komendę przyciskiem, wróć do terminala i naciśnij Ctrl + Shift + V (albo kliknij prawym przyciskiem → „Wklej”).
  • Jak zatwierdzić: po wklejeniu naciśnij Enter.
⚠️ Jeśli komenda zaczyna się od sudo, terminal poprosi o hasło (to samo, którym logujesz się do komputera). Podczas wpisywania nie widać kropek ani gwiazdek — to normalne. Wpisz hasło „w ciemno” i naciśnij Enter.

1 Pobierz program

  1. Na stronie pobierania kliknij duży przycisk „⬇ Pobierz na Linux”.
  2. Przeglądarka pobierze plik o nazwie ClaudeVoiceAssistant-linux.AppImage (ok. 190 MB — może chwilę zejść).
  3. Plik wyląduje w folderze Pobrane (po angielsku: Downloads) — tam, gdzie trafiają wszystkie Twoje pobrane pliki.
✅ Masz w folderze Pobrane plik z fioletową ikoną mikrofonu i nazwą kończącą się na .AppImage — świetnie, idziemy dalej.

2 Pozwól plikowi się uruchamiać

Linux z ostrożności traktuje świeżo pobrany plik jak „zwykły dokument” i nie pozwoli go uruchomić, dopóki sam nie potwierdzisz, że to program. Robi się to raz. Wybierz jeden z dwóch sposobów — sposób A działa zawsze.

Sposób A — przez terminal (pewny, polecany)

  1. Otwórz terminal: Ctrl + Alt + T.
  2. Wpisz chmod +x i jedną spację na końcu (nie naciskaj jeszcze Enter):
chmod +x
  1. Teraz przeciągnij myszką pobrany plik .AppImage prosto do okna terminala i upuść. Ścieżka do pliku dopisze się sama — nie musisz nic przepisywać.
  2. Naciśnij Enter. Brak komunikatu = sukces (tak działa terminal — cisza to dobra wiadomość).
💡 Cała linijka będzie wyglądać mniej więcej tak: chmod +x /home/twojanazwa/Pobrane/ClaudeVoiceAssistant-linux.AppImage

Sposób B — przez menedżer plików (jeśli Twój go obsługuje)

  1. Otwórz folder Pobrane, kliknij plik prawym przyciskiem myszy → Właściwości.
  2. Przejdź na zakładkę Uprawnienia.
  3. Zaznacz „Zezwól na wykonywanie pliku jako programu” i zamknij okno.
⚠️ Niektóre nowsze systemy (np. najnowsze Ubuntu) ukryły tę opcję w menedżerze plików. Jeśli nie widzisz takiego pola — po prostu użyj Sposobu A (terminal).

3 Uruchom program

Wróć do folderu Pobrane i kliknij dwa razy plik .AppImage. Po chwili powinno otworzyć się okno programu.

⚠️ Dwuklik nic nie robi albo pojawia się błąd o „libfuse.so.2”? To bardzo częste na nowszym Ubuntu — brakuje jednej małej biblioteki. Wklej w terminalu (Ctrl+Alt+T) tę komendę i naciśnij Enter:
sudo apt update && sudo apt install -y libfuse2

Potem spróbuj ponownie kliknąć plik dwa razy.

💡 Jeśli pojawi się okienko „Czy chcesz uruchomić…?” — potwierdź Uruchom / Run.

4 Dodaj „mózg” programu — Claude Code

Ten program sam nie myśli — jest pilotem do narzędzia Claude Code (to ono rozmawia i pisze kod). Claude Code jest darmowe i instaluje się raz. Jeśli program po uruchomieniu pokaże kreatora konfiguracji — po prostu wykonuj jego wskazówki. Wolisz zrobić to ręcznie? Otwórz terminal i wklej po kolei:

a) Node.js (darmowy program pomocniczy)

sudo apt update && sudo apt install -y nodejs npm

b) Claude Code

sudo npm install -g @anthropic-ai/claude-code
✅ Sprawdzenie: wpisz claude --version i naciśnij Enter. Pokazał się numer wersji? Mózg na miejscu.

5 Zaloguj się do Claude

  1. W terminalu wpisz claude i naciśnij Enter (albo zrób to w terminalu wewnątrz programu).
  2. Jeśli pojawi się pytanie o zaufanie do folderu — naciśnij Enter (tak).
  3. Claude Code poprosi o zalogowanie. Powinna otworzyć się przeglądarka — zaloguj się na konto Claude (claude.ai, np. plan Pro) i kliknij Autoryzuj.
  4. Skopiuj pokazany kod i wklej go w terminalu w miejscu „Paste code here”.
⚠️ Jeśli przeglądarka nie otworzy się sama — Claude Code pokaże długi link i podpowiedź „c to copy”. Naciśnij c (link skopiuje się do schowka), wklej go w przeglądarce. Nie przepisuj linku ręcznie.
🎉 Gotowe! Od teraz uruchamiasz program zwykłym dwuklikiem pliku .AppImage. Program sam się aktualizuje — gdy pojawi się nowa wersja, zaproponuje ją.

🛟 Coś nie działa? Szybka ściąga

  • Dwuklik nic nie robi. Najpewniej pominięty krok 2 (pozwolenie na uruchamianie) lub brak libfuse2 z kroku 3. Zrób oba i spróbuj ponownie.
  • „command not found: claude”. Brakuje mózgu — wróć do kroku 4.
  • Nie wiem, gdzie jest plik. Otwórz „Pliki” (menedżer plików) → folder Pobrane.
  • Terminal prosi o hasło i „nic się nie wpisuje”. To normalne — hasła nie widać. Wpisz je w ciemno i Enter.
  • Inny system niż Ubuntu (Fedora, Arch…)? Komendy apt mogą się różnić — napisz do nas, podpowiemy: kontakt@fulfillment-polska.pl.
