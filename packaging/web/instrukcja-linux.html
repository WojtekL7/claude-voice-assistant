⏳ Paczka dla Linuksa — wkrótce

Pracujemy nad gotowym plikiem AppImage, który uruchomi program na Linuksie bez instalacji — tak samo prosto jak na Windows i Macu. Gdy będzie gotowy, pojawi się na stronie pobierania, a ta instrukcja zostanie uzupełniona o szczegółowe kroki.

Masz Windows lub Maca? Zobacz gotowe instrukcje: Windows • macOS

1 Co możesz przygotować już teraz — Node.js i Claude Code

Program (jak na każdym systemie) potrzebuje dwóch darmowych dodatków: Node.js i Claude Code. Możesz zainstalować je już dziś — będą gotowe na premierę paczki. Otwórz terminal (Ctrl+Alt+T na Ubuntu) i wykonaj kolejno:

Node.js (Ubuntu/Debian):

sudo apt update && sudo apt install -y nodejs npm

Claude Code:

sudo npm install -g @anthropic-ai/claude-code
✅ Sprawdzenie: wpisz claude --version i naciśnij Enter — jeśli pokaże się numer wersji, wszystko gotowe.

2 Logowanie do Claude Code

  1. W terminalu wpisz claude i naciśnij Enter.
  2. Jeśli pojawi się pytanie o zaufanie do folderu — naciśnij Enter (tak).
  3. Claude Code poprosi o zalogowanie. Powinna otworzyć się przeglądarka — zaloguj się na konto Claude (claude.ai, plan np. Pro) i kliknij Autoryzuj.
  4. Skopiuj pokazany kod i wklej go w terminalu w miejscu „Paste code here”.
⚠️ Jeśli przeglądarka nie otworzy się sama — Claude Code pokaże długi link i podpowiedź „c to copy”. Naciśnij c (link skopiuje się do schowka), wklej go w przeglądarce. Nie przepisuj linku ręcznie.
