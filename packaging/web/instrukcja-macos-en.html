Installing on a Mac — step by step

We'll walk you all the way from downloading the file to your first chat with Claude Code. You don't need to know your way around computers — just do exactly what's below.

← Back to the download page

Before you start — what you'll need

  • A Mac with an Apple Silicon chip (M1, M2, M3 or M4) and an internet connection.
  • About 15 minutes.
  • A Claude account (claude.ai) with an active plan (e.g. Pro) — that's the account Claude Code will sign in to in the last step. If you don't have an account, create one at claude.ai.
Besides our app, we'll install two free add-ons: Node.js (a helper program) and Claude Code (the actual “brain” that our app controls). Without them the app will launch, but there'll be no one to talk to.

1 Download and install the app

  1. Go to the download page (if it asks for a username and password — enter the details you received from us) and click “⬇ Download for Mac”.
  2. Open the downloaded ClaudeVoiceAssistant-macos.dmg file (the Downloads folder).
  3. In the window that appears, drag the app icon into the “Applications” folder.
  4. Open Applications and double-click Claude Voice Assistant.
⚠️ On the first launch, macOS will show a warning that it can't verify the app (it doesn't have an Apple signature yet) — and it may NOT give you an “Open” button. Do this:
  1. Click OK in the warning.
  2. Open System Settings → Privacy & Security.
  3. Scroll all the way down — there'll be a note about the blocked app and an “Open Anyway” button. Click it and confirm (password or Touch ID).
You only need to do this once.
What you'll see: the app window with a black box in the middle. That box is the terminal — the place where you type commands for the computer. You type, press Enter, and the computer answers.
On the first launch, the app may also show a window saying “Finish setup — Claude Code is required.” That's our helper — it walks you through the same steps we describe below.

2 Install Node.js (a free add-on)

  1. Go to nodejs.org and click the green button labeled “LTS” (the stable version). The file will download.
  2. Open the downloaded file (e.g. node-v22….pkg) and click Next / Continue, agree to the license, and at the end Install (the Mac will ask for your password).
  3. After the “The installation was successful” message, click Close.

3 Install Claude Code

  1. Close our app completely (Cmd+Q) and start it again. This matters — the app needs to “see” the freshly installed Node.js.
  2. Copy the command below with the Copy button:
npm install -g @anthropic-ai/claude-code
  1. Click into the black box (terminal) in the app window, paste the command (Cmd+V) and press Enter.
  2. Wait 1–2 minutes. Text will scroll across the screen — that's normal.
✅ Success looks like this: at the end you'll see a line like “added 2 packages in 40s.”
⚠️ If you see “npm: command not found” — Node.js wasn't installed (go back to step 2) or the app wasn't restarted (close it with Cmd+Q and open it once more).

4 Launch Claude Code and sign in

  1. In the terminal (the black box), type claude and press Enter. Watch out for typos — “claude,” not “cloude.” Best to copy it: claude
  2. If you're asked whether you trust the folder (“Do you trust the files in this folder?”) — press Enter (yes).
  3. Claude Code will ask you to sign in. A browser should open — sign in to your Claude account and click Authorize.
  4. The browser will show a code — copy it, go back to the app, paste it where it says “Paste code here” and press Enter.
⚠️ If the browser does NOT open on its own: Claude Code will show a long link and a hint that says “c to copy.” Press the letter c on your keyboard — the link copies to your clipboard. Open your browser, click the address bar, paste (Cmd+V) and press Enter. Don't retype the link by hand — it's over 300 characters and a single typo breaks it.
✅ After a successful sign-in you'll see Claude Code's welcome in the terminal. From now on you can write to it like you would to a person.

5 Done! What's next

  • Type commands in the field at the bottom of the window or straight into the terminal, and press Enter.
  • Reading answers out loud works right away — turn on “auto-read” on the tab.
  • Voice dictation (the 🎤 microphone) needs a free Groq key. Create a free account and generate a key at console.groq.com/keys (the “Create API Key” button), then paste it into the app: the Settings → Groq API Key… menu. The first time you use it, macOS will ask for microphone permission — click “Allow.”
  • The app updates itself — when a new version comes out, it asks you with a single window, downloads it, swaps itself out and restarts.

Common problems

“claude: command not found” Claude Code isn't installed yet (step 3) or the app wasn't restarted after installing Node.js. Close the app (Cmd+Q) and open it once more.
No “Open” button on the first start System Settings → Privacy & Security → “Open Anyway” at the bottom.
The microphone does nothing The Groq key is missing — get a free one at console.groq.com/keys and paste it into Settings → Groq API Key… Or system permission is missing (System Settings → Privacy & Security → Microphone → enable it for the app).
The app disappeared after an update and won't come back Open the Applications folder and launch it by hand — it's a one-off; let us know if it repeats.
