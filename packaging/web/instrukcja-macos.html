Instalacja na Macu — krok po kroku

Przeprowadzimy Cię od pobrania pliku do pierwszej rozmowy z Claude Code. Nie musisz znać się na komputerach — wystarczy robić dokładnie to, co poniżej.

← Wróć do strony pobierania

Zanim zaczniesz — co będzie potrzebne

  • Mac z procesorem Apple Silicon (M1, M2, M3 lub M4) i dostęp do internetu.
  • Około 15 minut.
  • Konto Claude (claude.ai) z aktywnym planem (np. Pro) — to do niego zaloguje się Claude Code w ostatnim kroku. Jeśli nie masz konta, załóż je na claude.ai.
Oprócz naszego programu zainstalujemy dwa darmowe dodatki: Node.js (program pomocniczy) i Claude Code (właściwy „mózg”, którym nasz program steruje). Bez nich program się uruchomi, ale nie będzie z kim rozmawiać.

1 Pobierz i zainstaluj program

  1. Wejdź na stronę pobierania (jeśli poprosi o login i hasło — wpisz dane, które otrzymałeś od nas) i kliknij „⬇ Pobierz na Maca”.
  2. Otwórz pobrany plik ClaudeVoiceAssistant-macos.dmg (folder Pobrane).
  3. W oknie, które się pojawi, przeciągnij ikonę programu do folderu „Programy” (Applications).
  4. Otwórz Programy i kliknij dwukrotnie Claude Voice Assistant.
⚠️ Przy pierwszym uruchomieniu macOS pokaże ostrzeżenie, że nie może sprawdzić programu (nie ma on jeszcze podpisu Apple) — i może NIE dać przycisku „Otwórz”. Zrób tak:
  1. Kliknij OK w ostrzeżeniu.
  2. Otwórz Ustawienia systemowe → Prywatność i bezpieczeństwo.
  3. Przewiń na sam dół — będzie tam informacja o zablokowanym programie i przycisk „Otwórz mimo to”. Kliknij go i potwierdź (hasło lub Touch ID).
To trzeba zrobić tylko raz.
Co zobaczysz: okno programu z czarnym polem w środku. To pole to terminal — miejsce, w którym wpisuje się polecenia dla komputera. Piszesz, naciskasz Enter, komputer odpowiada.
Przy pierwszym uruchomieniu program może też pokazać okno „Dokończ instalację — potrzebny Claude Code”. To nasz pomocnik — prowadzi przez te same kroki, które opisujemy poniżej.

2 Zainstaluj Node.js (darmowy dodatek)

  1. Wejdź na nodejs.org i kliknij zielony przycisk z napisem „LTS” (wersja stabilna). Plik się pobierze.
  2. Otwórz pobrany plik (np. node-v22….pkg) i klikaj Dalej / Kontynuuj, zgódź się na licencję, na końcu Zainstaluj (Mac poprosi o hasło).
  3. Po napisie „Instalacja zakończona pomyślnie” kliknij Zamknij.

3 Zainstaluj Claude Code

  1. Zamknij nasz program całkowicie (Cmd+Q) i uruchom go ponownie. To ważne — program musi „zobaczyć” świeżo zainstalowany Node.js.
  2. Skopiuj poniższą komendę przyciskiem Kopiuj:
npm install -g @anthropic-ai/claude-code
  1. Kliknij myszką w czarne pole (terminal) w oknie programu, wklej komendę (Cmd+V) i naciśnij Enter.
  2. Poczekaj 1–2 minuty. Na ekranie będą przewijać się napisy — to normalne.
✅ Sukces wygląda tak: na końcu pojawi się napis w stylu „added 2 packages in 40s”.
⚠️ Jeśli zobaczysz „npm: command not found” — Node.js nie został zainstalowany (wróć do kroku 2) albo program nie został uruchomiony ponownie (zamknij go przez Cmd+Q i otwórz jeszcze raz).

4 Uruchom Claude Code i zaloguj się

  1. W terminalu (czarne pole) wpisz claude i naciśnij Enter. Uwaga na literówki — „claude”, nie „cloude”. Najlepiej skopiuj: claude
  2. Jeśli pojawi się pytanie o zaufanie do folderu („Do you trust the files in this folder?”) — naciśnij Enter (tak).
  3. Claude Code poprosi o zalogowanie. Powinna otworzyć się przeglądarka — zaloguj się na swoje konto Claude i kliknij Autoryzuj.
  4. Przeglądarka pokaże kod — skopiuj go, wróć do programu, wklej w miejscu „Paste code here” i naciśnij Enter.
⚠️ Jeśli przeglądarka NIE otworzy się sama: Claude Code wyświetli długi link i podpowiedź „c to copy”. Naciśnij na klawiaturze literę c — link skopiuje się do schowka. Otwórz przeglądarkę, kliknij w pasek adresu, wklej (Cmd+V) i naciśnij Enter. Nie przepisuj linku ręcznie — ma ponad 300 znaków i jedna literówka go psuje.
✅ Po udanym logowaniu zobaczysz powitanie Claude Code w terminalu. Od teraz możesz pisać do niego jak do człowieka.

5 Gotowe! Co dalej

  • Pisz polecenia w polu na dole okna albo wprost w terminalu i naciskaj Enter.
  • Czytanie odpowiedzi na głos działa od razu — włącz „auto-czytanie” przy zakładce.
  • Dyktowanie głosem (mikrofon 🎤) wymaga darmowego klucza Groq. Załóż darmowe konto i wygeneruj klucz na console.groq.com/keys (przycisk „Create API Key”), a potem wklej go w programie: menu Ustawienia → Klucz API Groq… Przy pierwszym użyciu macOS zapyta o zgodę na mikrofon — kliknij „Zezwól”.
  • Program aktualizuje się sam — gdy wyjdzie nowa wersja, zapyta jednym oknem, pobierze, podmieni się i uruchomi ponownie.

Najczęstsze problemy

„claude: command not found” Claude Code nie jest jeszcze zainstalowany (krok 3) albo program nie był uruchomiony ponownie po instalacji Node.js. Zamknij program (Cmd+Q) i otwórz go jeszcze raz.
Brak przycisku „Otwórz” przy pierwszym starcie Ustawienia systemowe → Prywatność i bezpieczeństwo → na dole „Otwórz mimo to”.
Mikrofon nic nie robi Brakuje klucza Groq — załóż darmowy na console.groq.com/keys i wklej w Ustawienia → Klucz API Groq… Albo brak zgody systemowej (Ustawienia systemowe → Prywatność i bezpieczeństwo → Mikrofon → włącz dla programu).
Program zniknął po aktualizacji i nie wraca Otwórz folder Programy i uruchom go ręcznie — to jednorazowe; zgłoś nam, jeśli się powtórzy.
