Complete guide — Windows

From zero to your first conversation, in order. Written for someone doing this for the first time. The app itself installs by clicking — a terminal appears only once, when adding the “brain”.

📍 What we'll do — in order

  1. Download and install the app
  2. Add the “brain” — Claude Code
  3. Create a Claude account and pick a plan
  4. Connect the account to the app (login)
  5. Check it works — and what to do if it doesn't

🧭 Before we start — two paths

This app (Claude Voice Assistant) is a remote control: it gives you voice, tabs and a comfortable window. The thinking is done by Claude Code, and for it to work it needs your Claude account.

On Windows the app installs entirely by clicking (a normal installer). The choice of path applies to just one moment — adding the “brain” in part 2:

A With a terminal (PowerShell) — you paste a ready command. Reliable, always works.
B Without a terminal — a wizard in the app guides you. For non-technical users.
⚠️ A bit of honesty: installing Claude Code has no click-through installer — you run it once in a PowerShell window. On path B the app gives you a ready command with a Copy button, so you just paste and Enter.
💜 You never retype anything by hand — every command has a Copy button.

1 Download and install the app

  1. On the download page click “⬇ Download for Windows”.
  2. It downloads ClaudeVoiceAssistant-Setup.exe into your Downloads folder.
  3. Double-click it and go through the installer (a few clicks of “Next / Install”).
⚠️ A blue “Windows protected your PC” screen appeared? That's normal for new programs. Click “More info”, then “Run anyway”.
✅ After installing, the app is in the Start menu. Launch it — you'll need it in part 2.

2 Add the “brain” — Claude Code

The app doesn't think on its own — it needs Claude Code (a free add-on, installed once, together with the helper Node.js).

B Without a terminal — let the app guide you (recommended)
  1. Launch Claude Voice Assistant. If it can't find Claude Code, it shows a “Finish setup” window.
  2. Click “Get Node.js” — it opens nodejs.org. Download the LTS version and install it (click “Next”, like any program). After installing Node, restart the app so it notices it.
  3. The “Finish setup” window has a ready command and a Copy button. This is the one moment with a terminal: open PowerShell (see below), paste the command (right-click or Ctrl+V) and press Enter.
  4. Go back to the app window and click “Check again”. The app finds the brain and moves on.
💡 How to open PowerShell: click the Start menu, type PowerShell and press Enter. A dark-blue window opens — that's our “terminal”.
💡 You can open the “Finish setup” window yourself: menu Help → Claude Code setup.
A With a terminal — by yourself
  1. Install Node.js (LTS) from nodejs.org (a normal installer, click “Next”).
  2. Open PowerShell (Start → type “PowerShell” → Enter) and paste:
npm install -g @anthropic-ai/claude-code
✅ Check: type claude --version and Enter. See a number? The brain is in place.

3 Create a Claude account and pick a plan

For Claude Code to work you need a Claude account with paid access. You can do this earlier too — what matters is that it's ready before the login in part 4.

3.1 Create the account

  1. Go to claude.ai (button below) and click “Sign up”.
  2. Choose to sign up with an email or a Google account.
  3. With email — confirm using the code/link from your inbox (check Spam too).
🔗 Open claude.ai and sign up

3.2 Pick a plan

A free account is enough for chatting on the website, but Claude Code needs paid access. Two routes:

💜 Pro / Max plan — recommended

A fixed monthly fee on your claude.ai account. Simplest: pay once a month and log in with that account. Pro is enough to start, Max gives you more for heavy use.

🔧 Pay via the API (advanced)

“Pay as you go” billing in the console.anthropic.com dashboard. More fiddly — skip it unless you know you need it.

🔗 Choose a plan on claude.ai
💡 Not sure? Start with Claude Pro — you can change or cancel any time.

4 Connect the account to the app (login)

Now we connect the account to the app — done inside the app, once.

  1. A terminal (a dark panel) appears in the app. The first time you start an agent, Claude Code asks you to log in.
  2. A browser should open — sign in to your Claude account (from part 3) and click “Authorize”.
  3. The browser shows a code. Copy it and paste it into the app where it says “Paste code here”, then Enter.
⚠️ Browser didn't open by itself? Claude Code shows a long link and a hint “press c to copy”. Press c (the link goes to the clipboard), paste it in your browser. Don't retype the link by hand.

5 Check it works — and what to do if it doesn't

✅ Quick test

  • An agent tab with a working terminal has appeared.
  • Type or say: “Hi, are you working?” — Claude replies, and the app reads the answer out loud.
  • From now on you launch the app from the Start menu — and it updates itself.
🎉 Claude replies? You're all set. Enjoy!

🛟 Something not working? Cheat sheet

  • “'claude' is not recognized”. The brain is installed but the app doesn't see it yet — close and reopen the app (sometimes you need to restart the computer so the system picks up the new add-on). Still nothing? Go back to part 2.
  • “Windows protected your PC”. Click More info → Run anyway (part 1).
  • The app keeps asking you to log in. Sign in with the account that has a paid plan (part 3) — a free one isn't enough.
  • The browser won't open during login. Use the c method (part 4).
