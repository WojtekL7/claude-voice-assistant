Instalacja na Windows — krok po kroku

Przeprowadzimy Cię od pobrania pliku do pierwszej rozmowy z Claude Code. Nie musisz znać się na komputerach — wystarczy robić dokładnie to, co poniżej.

← Wróć do strony pobierania

Zanim zaczniesz — co będzie potrzebne

  • Komputer z Windows 10 lub 11 i dostęp do internetu.
  • Około 15 minut.
  • Konto Claude (claude.ai) z aktywnym planem (np. Pro) — to do niego zaloguje się Claude Code w ostatnim kroku. Jeśli nie masz konta, załóż je na claude.ai.
Oprócz naszego programu zainstalujemy dwa darmowe dodatki: Node.js (program pomocniczy) i Claude Code (właściwy „mózg”, którym nasz program steruje). Bez nich program się uruchomi, ale nie będzie z kim rozmawiać.

1 Pobierz i zainstaluj program

  1. Wejdź na stronę pobierania (jeśli poprosi o login i hasło — wpisz dane, które otrzymałeś od nas) i kliknij „⬇ Pobierz na Windows”.
  2. Po pobraniu otwórz plik — kliknij go w pasku przeglądarki albo znajdź w folderze Pobrane i kliknij dwukrotnie. Nazwa pliku to ClaudeVoiceAssistant-Setup.exe.
  3. Może pojawić się niebieski ekran „System Windows ochronił ten komputer”. To standardowe ostrzeżenie dla nowych programów — kliknij „Więcej informacji”, a potem przycisk „Uruchom mimo to”.
  4. W instalatorze klikaj Dalej → Zainstaluj → Zakończ. Program uruchomi się sam.
Co zobaczysz: okno programu z czarnym polem w środku. To pole to terminal — miejsce, w którym wpisuje się polecenia dla komputera. Piszesz, naciskasz Enter, komputer odpowiada. Będziemy z niego korzystać za chwilę.
Przy pierwszym uruchomieniu program może też pokazać okno „Dokończ instalację — potrzebny Claude Code”. To nasz pomocnik — prowadzi przez te same kroki, które opisujemy poniżej. Możesz iść za nim albo za tą stroną, to to samo.

2 Zainstaluj Node.js (darmowy dodatek)

  1. Wejdź na nodejs.org i kliknij zielony przycisk z napisem „LTS” (to wersja stabilna). Plik się pobierze.
  2. Otwórz pobrany plik (np. node-v22…-x64.msi) i klikaj Next, zaznacz zgodę na licencję, znowu Next — niczego nie zmieniaj.
  3. Na ekranie „Tools for Native Modules” NIE zaznaczaj kratki — po prostu kliknij Next, potem Install i Finish.
⚠️ Jeśli mimo wszystko zaznaczysz tę kratkę (albo już zaznaczyłeś): po instalacji otworzy się czarne okno, które wypisze groźnie wyglądające błędy (np. „Didn't find any channel feed”). To nieszkodliwe — Node.js jest już zainstalowany. Po prostu zamknij to okno krzyżykiem i idź dalej.

3 Zainstaluj Claude Code

  1. Zamknij nasz program całkowicie i uruchom go ponownie (ikona na pulpicie). To ważne — program musi „zobaczyć” świeżo zainstalowany Node.js.
  2. Skopiuj poniższą komendę przyciskiem Kopiuj:
npm install -g @anthropic-ai/claude-code
  1. Kliknij myszką w czarne pole (terminal) w oknie programu, wklej komendę (Ctrl+V albo prawy przycisk myszy → Wklej) i naciśnij Enter.
  2. Poczekaj 1–2 minuty. Na ekranie będą przewijać się napisy — to normalne.
✅ Sukces wygląda tak: na końcu pojawi się napis w stylu „added 2 packages in 40s”.
⚠️ Jeśli zobaczysz „'npm' is not recognized…” — Node.js nie został zainstalowany (wróć do kroku 2) albo program nie został uruchomiony ponownie (zamknij go i otwórz jeszcze raz).

4 Uruchom Claude Code i zaloguj się

  1. W terminalu (czarne pole) wpisz claude i naciśnij Enter. Uwaga na literówki — „claude”, nie „cloude”. Najlepiej skopiuj: claude
  2. Jeśli pojawi się pytanie o zaufanie do folderu („Do you trust the files in this folder?”) — naciśnij Enter (tak).
  3. Claude Code poprosi o zalogowanie. Powinna otworzyć się przeglądarka — zaloguj się na swoje konto Claude i kliknij Autoryzuj.
  4. Przeglądarka pokaże kod — skopiuj go, wróć do programu, wklej w miejscu „Paste code here” i naciśnij Enter.
⚠️ Jeśli przeglądarka NIE otworzy się sama: Claude Code wyświetli długi link i podpowiedź „c to copy”. Naciśnij na klawiaturze literę c — link skopiuje się do schowka. Otwórz przeglądarkę, kliknij w pasek adresu, wklej (Ctrl+V) i naciśnij Enter. Nie przepisuj linku ręcznie — ma ponad 300 znaków i jedna literówka go psuje.
✅ Po udanym logowaniu zobaczysz powitanie Claude Code w terminalu. Od teraz możesz pisać do niego jak do człowieka.

5 Gotowe! Co dalej

  • Pisz polecenia w polu na dole okna albo wprost w terminalu i naciskaj Enter.
  • Czytanie odpowiedzi na głos działa od razu — włącz „auto-czytanie” przy zakładce.
  • Dyktowanie głosem (mikrofon 🎤) wymaga darmowego klucza Groq. Załóż darmowe konto i wygeneruj klucz na console.groq.com/keys (przycisk „Create API Key”), a potem wklej go w programie: menu Ustawienia → Klucz API Groq…
  • Program aktualizuje się sam — gdy wyjdzie nowa wersja, zapyta jednym oknem.

Najczęstsze problemy

„'claude' is not recognized…” Claude Code nie jest jeszcze zainstalowany (krok 3) albo program nie był uruchomiony ponownie po instalacji Node.js. Zamknij program i otwórz go jeszcze raz.
Czarne okno z błędami po instalacji Node.js Nieszkodliwy efekt opcji „Tools for Native Modules”. Zamknij okno i działaj dalej.
„System Windows ochronił ten komputer” Kliknij „Więcej informacji”, potem „Uruchom mimo to”. Program nie ma jeszcze podpisu cyfrowego — stąd ostrzeżenie.
Aktualizacja nie chce się pobrać (błąd SSL) Pobierz instalator najnowszej wersji przez przeglądarkę ze strony pobierania i uruchom go — ustawienia zostaną zachowane.
Mikrofon nic nie robi Brakuje klucza Groq — załóż darmowy na console.groq.com/keys i wklej w Ustawienia → Klucz API Groq… Albo Windows blokuje mikrofon (Ustawienia systemu → Prywatność → Mikrofon).
