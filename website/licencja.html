2. Czym jest Aplikacja

Vibe Coding Assistant to nakładka („pilot") na narzędzie Claude Code firmy Anthropic, dodająca obsługę głosem (dyktowanie i czytanie odpowiedzi), zakładki wielu agentów oraz menedżer MCP i Skills.

Aplikacja nie zawiera ani nie hostuje modelu AI, ani konta Claude Code. Do działania wymaga, abyś we własnym zakresie posiadał i skonfigurował Claude Code oraz odpowiednie konto Anthropic. Korzystanie z Claude Code, modeli AI i innych usług podlega regulaminom ich dostawców.
